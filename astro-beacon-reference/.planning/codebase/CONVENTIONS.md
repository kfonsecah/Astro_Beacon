# Coding Conventions

**Analysis Date:** 2026-04-01

## Project Context

This is a **visual reference web app** generated by Lovable (IA) for the Astro Beacon project. It serves as a UI/UX reference for a React Native mobile app. The project uses a **space/terminal aesthetic** with dark backgrounds, glowing cyan accents, and monospace typography.

## Naming Patterns

**Files:**
- PascalCase for React components: `SpaceCard.tsx`, `BottomNav.tsx`, `Dashboard.tsx`
- kebab-case not used — all component files use PascalCase
- Test files use kebab-case with `.test.` suffix: `example.test.ts`

**Components:**
- Custom space-themed components live in `src/components/space/` (e.g., `SpaceCard.tsx`, `HudIndicator.tsx`)
- Reusable UI components from shadcn/ui live in `src/components/ui/` (e.g., `button.tsx`, `card.tsx`, `input.tsx`)
- Page-level components live in `src/pages/` and are named after screen/route (e.g., `Dashboard.tsx`, `Bestiary.tsx`)

**Functions/Hooks:**
- camelCase for functions: `cn()`, `genId()`, `dispatch()`
- Custom hooks use `use` prefix: `useIsMobile()`, `useToast()`
- Hook files named `use-kebab-case.tsx`: `use-mobile.tsx`, `use-toast.ts`

**Variables:**
- camelCase for local variables and state: `searchQuery`, `isAuthenticating`, `filtered`
- UPPERCASE for constants and config objects: `TOAST_LIMIT`, `MOBILE_BREAKPOINT`, `statusConfig`
- Static data arrays use lowercase plural: `species`, `resources`, `history`, `tabs`

**Types/Interfaces:**
- PascalCase with `Props` suffix for component props: `SpaceCardProps`, `HudIndicatorProps`, `ButtonProps`
- PascalCase for type aliases: `ToasterToast`, `Action`, `State`

## Code Style

**Formatting:**
- No explicit Prettier config detected — relies on Lovable defaults
- 2-space indentation throughout
- Semicolons used consistently
- Single quotes for strings in JSX attributes, double quotes for imports

**Linting:**
- ESLint 9.x with flat config (`eslint.config.js`)
- Extends: `@eslint/js/recommended`, `typescript-eslint/recommended`
- Plugins: `react-hooks` (recommended rules), `react-refresh`
- Relaxed TypeScript rules: `noUnusedVars: off`, `noImplicitAny: off`, `strictNullChecks: off`
- `react-refresh/only-export-components` set to warn (allows constant exports)

**TypeScript:**
- TSX used throughout (`.tsx` extension for all React files)
- `skipLibCheck: true`, `allowJs: true`
- Path alias `@/*` maps to `./src/*`

## Import Organization

**Order:**
1. External library imports (React, framer-motion, react-router-dom, lucide-react)
2. Internal imports using `@/` path alias
3. Relative imports (used sparingly, e.g., `./pages/Splash` in App.tsx)

**Path Aliases:**
- `@/components/*` → `src/components/*`
- `@/lib/*` → `src/lib/*`
- `@/hooks/*` → `src/hooks/*`

**Default vs Named Exports:**
- Custom space components use **default exports**: `export default SpaceCard`
- shadcn/ui components use **named exports**: `export { Button, buttonVariants }`
- Hooks use **named exports**: `export { useIsMobile }`, `export { useToast, toast }`
- Utility functions use **named exports**: `export function cn(...)`

## UI/Visual Conventions

**Color System (HSL via CSS Variables):**
All colors use CSS custom properties in `src/index.css`. The space theme defines:

| Token | HSL Value | Usage |
|-------|-----------|-------|
| `--space-black` | 240 100% 3% | Deepest background |
| `--deep-navy` | 220 68% 11% | Primary background |
| `--cyan-glow` | 160 100% 70% | Primary text, accents, glows |
| `--warning-orange` | 20 100% 70% | Alerts, critical states |
| `--alien-green` | 100 100% 70% | Discovery, success states |
| `--faint-gray` | 220 18% 61% | Muted text, secondary info |
| `--cosmic-blue` | 217 91% 60% | Accent highlights |

**Typography:**
- **Headings**: `font-mono` (IBM Plex Mono), `tracking-wider`, `uppercase`
- **Body text**: `font-body` (Space Grotesk)
- **HUD/labels**: `font-mono`, `text-[9px]` to `text-[10px]`, `tracking-[0.2em]` to `tracking-[0.5em]`
- **Titles**: `font-mono`, `text-sm` to `text-2xl`, `tracking-[0.2em]`

**Glow Effects (custom utility classes in `src/index.css`):**
- `.text-glow-cyan` — cyan text shadow for primary text
- `.text-glow-orange` — orange text shadow for warnings
- `.text-glow-green` — green text shadow for discoveries
- `.border-glow` — cyan box shadow for card borders
- `.border-glow-orange` — orange box shadow for alert borders

**Background Effects:**
- `.scanline` — repeating horizontal lines overlay (CRT effect)
- `.grid-pattern` — subtle grid background
- `.flicker` — subtle opacity animation

**Layout Pattern (every page follows this):**
```tsx
<div className="min-h-screen bg-background pb-24">
  <div className="fixed inset-0 scanline pointer-events-none z-40" />
  
  <header className="sticky top-0 z-30 bg-card/95 backdrop-blur-sm border-b border-primary/10 px-4 py-3">
    {/* HUD header content */}
  </header>
  
  <main className="px-4 py-4 space-y-4 max-w-lg mx-auto">
    {/* Page content wrapped in SpaceCard components */}
  </main>
  
  <FloatingActionButton />
  <BottomNav />
</div>
```

**SpaceCard Component Pattern:**
- Used as the primary content container on all pages
- Variants: `"default"` (cyan border), `"alert"` (orange/red border), `"discovery"` (green border)
- Optional `title` prop renders a monospace uppercase header
- Always wraps content sections with `space-y-4` gaps between cards

**Animation Pattern (framer-motion):**
- Page entries: `initial={{ opacity: 0, y: 10 }}` → `animate={{ opacity: 1, y: 0 }}` with staggered `delay`
- List items: `initial={{ opacity: 0, x: -10 }}` → `animate={{ opacity: 1, x: 0 }}` with `delay: i * 0.05`
- Buttons: `whileTap={{ scale: 0.9 }}` or `whileTap={{ scale: 0.98 }}`
- Pulsing indicators: `animate={{ opacity: [0.5, 1, 0.5] }}` with `repeat: Infinity`
- Progress bars: `initial={{ width: 0 }}` → `animate={{ width: `${progress}%` }}`

**Icon Library:**
- **lucide-react** for all icons
- Icons used as components with `size` and `strokeWidth` props
- Common icons: `Home`, `BookOpen`, `Package`, `FileText`, `Search`, `Camera`, `AlertTriangle`, `MapPin`, `Zap`, `Activity`, `ArrowLeft`, `Volume2`, `Plus`, `Minus`, `TrendingUp`, `TrendingDown`, `Radar`

## Error Handling

**Patterns:**
- No centralized error boundary detected
- Pages use conditional rendering for empty/missing states
- `SpeciesDetail` falls back to default data: `speciesData[id || "1"] || speciesData["1"]`
- Form validation is manual (e.g., `if (!agentId.trim()) return`)
- Critical values use visual indicators (color change + blinking) rather than error messages
- `isCritical` logic: `value < 15` triggers destructive color and animation

**No try/catch blocks** — this is a visual reference with hardcoded data, no async operations

## Logging

- No logging framework used
- `console.log` not present in any source file
- Visual feedback replaces console logging (toast notifications via `sonner`, state indicators)

## Comments

- Minimal comments in source files
- JSDoc not used
- Comments appear only for section markers in CSS (`/* Space theme tokens */`, `/* Gradients */`)
- One inline comment in `use-toast.ts`: `// ! Side effects !`

## Function Design

**Size:** Components range from 20 lines (`FloatingActionButton`) to 204 lines (`Dashboard`). Most are 35-120 lines.

**Parameters:** Props objects with optional fields and defaults:
```tsx
const HudIndicator = ({ label, value, unit = "%", critical = false, icon }: HudIndicatorProps)
```

**Return Values:** All components return JSX. Some return `null` conditionally:
```tsx
if (!isScanning) return null;  // ScanAnimation
```

## Module Design

**Exports:**
- Each page is a default export
- Space components are default exports
- UI components (shadcn) use named exports
- No barrel files (no `index.ts` re-exporting modules)

**State Management:**
- Local `useState` for component-level state
- `useEffect` for timers and intervals
- No global state management (Redux, Zustand, etc.)
- `@tanstack/react-query` is configured but not actively used (hardcoded data)

## CSS/Tailwind Conventions

**Class Composition:**
- Uses `cn()` utility (`src/lib/utils.ts`) for conditional class merging
- Template literals used directly for simple conditionals: `` `text-${color}` ``

**Spacing:**
- Consistent use of Tailwind spacing scale: `px-4`, `py-3`, `gap-2`, `space-y-4`
- Mobile-first: `max-w-lg mx-auto` constrains content width

**Custom Utilities (in `src/index.css`):**
- `.text-glow-cyan`, `.text-glow-orange`, `.text-glow-green` — text shadows
- `.border-glow`, `.border-glow-orange` — box shadows
- `.scanline` — CRT scanline overlay
- `.grid-pattern` — subtle grid background
- `.animate-pulse-glow`, `.animate-scan-line` — custom animations

**Scrollbar Styling:** Custom webkit scrollbar (4px width, cyan thumb)
