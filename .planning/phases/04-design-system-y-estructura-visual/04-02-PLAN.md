4. `src/theme/index.ts` — Define `AppTheme` type (extends `@react-navigation/native` Theme type with spacing and typography). Barrel export all themes and the type.

Per research pitfall #2: Theme must be compatible with React Navigation's Theme interface (requires `dark: boolean` and `colors: Record<string, string>`).</action>
