<!-- Theme hook returns different theme based on system color scheme -->
From src/hooks/use-theme.ts:
```typescript
export function useTheme() {
  const colorScheme = useColorScheme();
  const isDark = colorScheme !== 'light';
  return isDark ? darkTheme : lightTheme;
}
```

Key insight: Theme is AUTOMATIC based on system color scheme (useColorScheme).
There is NO manual theme toggle in the app currently.
- Dark theme: Uses colors from constants/colors.ts (dark space HUD aesthetic)
- Light theme: Uses inline hex values in theme/light.ts (clean, bright aesthetic)
