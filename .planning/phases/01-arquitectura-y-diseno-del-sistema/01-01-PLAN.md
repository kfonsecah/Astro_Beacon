# Plan 01-01: Crear diagrama de arquitectura

**Phase:** 01 - Arquitectura y Diseño del Sistema
**Goal:** Crear diagrama de arquitectura draw.io con componentes y relaciones

## What This Delivers

Un archivo draw.io (`.drawio` XML) con 3 páginas de diagramas que demuestran "esfuerzo alto" según la rúbrica:
1. **System-Level Architecture** — App → API → DB + servicios externos
2. **Frontend Internal Architecture** — Capas internas del frontend
3. **Backend 3-Layer Architecture** — Controller → Service → Repository

## Tasks

### Task 1: Crear archivo draw.io con 3 páginas

**Output:** `docs/diagrams/architecture.drawio`

**Página 1 - System-Level:**
- Mobile App (React Native/Expo) — color azul
- API REST Server (Node.js/Express) — color verde
- MongoDB Database — color morado
- External Services — color naranja:
  - AI Classification API (OpenAI Vision)
  - Maps SDK (expo-maps / react-native-maps)
  - Push Notifications
- Flechas con etiquetas de protocolo (HTTPS/REST, JSON)
- Leyenda explicativa

**Página 2 - Frontend Internal:**
- Route Layer: `(auth)/`, `(app)/` con expo-router
- Screen Layer: Dashboard, Bitácora, Mapa, Recursos, Perfil
- Hook Layer: useAuth, useResources, useSpecies, useOffline
- Service Layer: api.ts, storage.ts, sync.service.ts
- State Layer: Zustand stores
- UI Component Layer: space/, ui/, common/
- Flechas de dependencia: Screens → Hooks → Services → State

**Página 3 - Backend 3-Layer:**
- Routes → Controllers → Services → Repositories → MongoDB
- Middleware stack: Auth, Validation, Error Handling
- Swagger/OpenAPI documentation layer
- AI Classification integration point

### Task 2: Exportar versión visual PNG

**Output:** `docs/diagrams/architecture-system.png`, `architecture-frontend.png`, `architecture-backend.png`

Para incluir en documentación y presentación.
