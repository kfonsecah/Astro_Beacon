### Task 2: Escribir ARCHITECTURE-DESIGN.md

**Output:** `docs/ARCHITECTURE-DESIGN.md`

**Secciones requeridas:**

1. **Introducción** — Contexto del proyecto, objetivo del documento
2. **Arquitectura General** — Diagrama de sistema (referencia al draw.io), descripción de capas
3. **Frontend (React Native + Expo)**
   - Arquitectura de carpetas (estructura del profesor)
   - Patrón presentación-contenedor (D-04) — justificación + ejemplo
   - Custom hooks como abstracción (D-05) — justificación + ejemplo
   - Service layer (D-06) — justificación + ejemplo
   - Navegación con expo-router (D-09) — route groups, typed routes
   - State management con Zustand — por qué sobre Redux/Context
   - Animaciones con Reanimated 4 — adaptación del reference project
4. **Backend (API REST)**
   - Arquitectura 3 capas: Controller → Service → Repository (D-07)
   - MongoDB como base de datos (D-08) — justificación NoSQL
   - API versionada v1 con Swagger/OpenAPI (D-03)
   - Autenticación JWT
5. **Comunicación Frontend-Backend**
   - API REST endpoints planificados
   - Manejo de errores
   - Offline sync strategy
6. **Servicios Externos**
   - AI Classification (OpenAI Vision)
   - Maps/GPS (expo-maps)
   - Camera, Audio, Location
7. **Patrones de Diseño Aplicados**
   - Presentación-contenedor
   - Repository pattern (backend)
   - Service layer abstraction
   - Observer pattern (NetInfo, Zustand subscriptions)
8. **Decisiones Técnicas Justificadas**
   - Tabla de decisiones con rationale (por qué X sobre Y)
   - Referencia al reference project y adaptación a RN
9. **Consideraciones de Seguridad**
   - JWT + expo-secure-store
   - Session timeout
   - Input validation con Zod
10. **Referencias** — Links a documentación oficial, reference project
