## Spacing Scale

Project-specific scale from `src/constants/spacing.ts`. Use these exact values — never raw pixel literals.

| Token | Value | Usage |
|-------|-------|-------|
| `spacing.xs` | 4px | Icon gaps, badge inner padding |
| `spacing.sm` | 8px | Chip gap, button inner padding |
| `spacing.md` | 12px | Default element spacing |
| `spacing.lg` | 16px | Section padding, card inner padding |
| `spacing.xl` | 20px | Between form fields |
| `spacing['2xl']` | 24px | Between major sections |
| `spacing['3xl']` | 32px | Layout gaps, image preview margin |
| `spacing['4xl']` | 40px | FAB bottom offset from screen edge |
| `spacing['5xl']` | 48px | Empty state vertical padding |
| `spacing['6xl']` | 64px | Page-level spacing |

Exception: border width = 1px or 2px (not a spacing token — used for HUD line rendering only, e.g. chip borders, card borders). Do not reference `spacing.xxs` for layout.

Exceptions:
- Species image preview height: 200px (fixed — matches `<Image>` display for base64 URIs per RESEARCH.md)
- FAB touch target: 56px width × 56px height (accessibility minimum for floating action button)
- Chip selector row height: 44px (minimum touch target for classification/danger pickers)

> Source: `src/constants/spacing.ts` — all values locked, no overrides needed for this phase.

## Typography

All text uses monospace font (`typography.fontFamily.mono`). Letter spacing is wide by default to reinforce HUD aesthetic. Use `typography.*` tokens only — no raw values.

| Role | Token | Size | Weight | Line Height | Letter Spacing |
|------|-------|------|--------|-------------|----------------|
| Body | `typography.fontSize.base` | 11px | 400 (`fontWeight.normal`) | `typography.lineHeight.normal` (18px) | `typography.letterSpacing.normal` (2) |
| Label / Badge | `typography.fontSize.xs` | 8px | 400 | `typography.lineHeight.tight` (16px) | `typography.letterSpacing.tight` (1) |
| Heading / Screen title | `typography.fontSize['2xl']` | 16px | 700 (`fontWeight.bold`) | `typography.lineHeight.relaxed` (22px) | `typography.letterSpacing.wide` (3) |
| Display / Species name | `typography.fontSize['3xl']` | 18px | 700 | `typography.lineHeight.relaxed` (22px) | `typography.letterSpacing.wider` (4) |

Declared sizes: 4 (8px, 11px, 16px, 18px). Declared weights: 2 (400, 700).

Note: Heading (16px) and Display (18px) are 2px apart. Visual separation is carried by letter-spacing differential (wide=3 vs wider=4) and context (screen title vs species name hierarchy). `typography.fontSize['4xl']` exists at 28px — too large a jump for Display; keep 18px. No size change needed.

> Source: `src/constants/typography.ts`. The xs/sm sizes (8, 9, 10) exist in the scale but xs=8 is Badge-specific; base=11 is the floor for readable body text in this phase.

## Interaction Contract

### Navigation
| Trigger | Action | Method |
|---------|--------|--------|
| Tap species card in `bestiary.tsx` | Open `species/[id]` | `router.push('/species/' + item.id)` |
| Tap FAB in `bestiary.tsx` | Open `species/identify` modal | `router.push('/species/identify')` |
| Successful save in `identify.tsx` | Return to bestiary | `router.back()` — cache invalidation handled by `useCreateSpecies` |
| Back button in `identify.tsx` | Dismiss modal | Default Expo Router back behavior |

### State Transitions — `identify.tsx`
| State | Image area | Form | Save button |
|-------|-----------|------|-------------|
| Initial | EmptyState placeholder | All fields empty | Enabled (but will validate on press) |
| Image selected | `<Image>` preview | — | Enabled |
| Loading (saving) | unchanged | disabled | ActivityIndicator inline |
| Error (save failed) | unchanged | unchanged | Re-enabled + error message below |

### ChipSelector — interaction rules
- Single selection only (one chip active at a time per group)
- Active chip: border `tc.primary`, text `tc.primary`, bg `tc.primaryMuted`
- Inactive chip: border `tc.border`, text `tc.textSecondary`, bg transparent
- Zero border-radius on all chips (HUD aesthetic per D-19/CONTEXT.md)
- Minimum tap area: 44px height (spacing exception declared above)

### Disabled buttons
- "IDENTIFICAR CON IA" and "NARRAR ESPECIE": `opacity: 0.4`, `pointerEvents: 'none'`
- No tooltip or explanation shown in this phase (Phase 25 will enable them)
