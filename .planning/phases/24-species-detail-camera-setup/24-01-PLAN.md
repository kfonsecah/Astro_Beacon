<task type="auto">
  <name>Crear hook useImagePicker</name>
  <files>src/hooks/useImagePicker.ts</files>
  <action>
    Implementar el hook `useImagePicker` en `src/hooks/useImagePicker.ts` (per D-06):
    1. Solicitar permisos con `ImagePicker.requestCameraPermissionsAsync()` antes de abrir cámara.
    2. `pickFromCamera`: llama a `ImagePicker.launchCameraAsync()` con `{ mediaTypes: ImagePicker.MediaTypeOptions.Images, quality: 0.4, allowsEditing: true, aspect: [4, 3], base64: true, exif: false }`.
    3. `pickFromGallery`: llama a `ImagePicker.launchImageLibraryAsync()` con los mismos parámetros.
    4. Contrato de estado/errores:
       - Si el usuario cancela (`result.canceled === true`): no actualizar estado, no lanzar error.
       - Si el permiso es denegado (`granted === false`): si `canAskAgain === false`, mostrar Alert HUD indicando que debe habilitar el permiso en Configuración del sistema; si `canAskAgain === true`, simplemente retornar sin abrir.
       - Si el sistema lanza error: capturar con try/catch, no crashear.
    5. `image`: estado `{ uri: string; base64: string } | null` — base64 con prefijo `data:image/jpeg;base64,${assets[0].base64}`. Derivar MIME del asset si está disponible; usar `image/jpeg` como fallback.
    6. `clearImage`: función para resetear el estado.
    El hook retorna: `{ pickFromCamera, pickFromGallery, image, clearImage }`.
    NO usar expo-image-manipulator — la compresión se maneja directamente con los parámetros de expo-image-picker (per D-03).
  </action>
