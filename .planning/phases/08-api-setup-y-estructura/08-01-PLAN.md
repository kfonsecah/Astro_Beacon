<task type="auto">
  <name>Task 3: Create .env.example and config loader</name>
  <files>api/.env.example, api/src/config/index.ts</files>
  <read_first>api/.env.example (new), api/src/config/index.ts (new)</read_first>
  <action>
    Create api/.env.example with:
    ```
    # Server
    PORT=3000
    NODE_ENV=development

    # Database
    MONGODB_URI=mongodb://localhost:27017/astro_beacon

    # JWT
    JWT_SECRET=your-super-secret-key-change-in-production
    JWT_EXPIRES_IN=15m
    JWT_REFRESH_EXPIRES_IN=7d

    # Rate Limiting
    RATE_LIMIT_WINDOW_MS=900000
    RATE_LIMIT_MAX_REQUESTS=100

    # CORS
    ALLOWED_ORIGINS=http://localhost:8081,http://localhost:3000
    ```

    Create api/src/config/index.ts:
    ```typescript
    import dotenv from 'dotenv';
    dotenv.config();

    export const config = {
      PORT: parseInt(process.env.PORT || '3000', 10),
      NODE_ENV: process.env.NODE_ENV || 'development',
      
      DATABASE: {
        URI: process.env.MONGODB_URI || 'mongodb://localhost:27017/astro_beacon'
      },
      
      JWT: {
        SECRET: process.env.JWT_SECRET || 'dev-secret-change-in-production',
        EXPIRES_IN: process.env.JWT_EXPIRES_IN || '15m',
        REFRESH_EXPIRES_IN: process.env.JWT_REFRESH_EXPIRES_IN || '7d'
      },
      
      RATE_LIMIT: {
        WINDOW_MS: parseInt(process.env.RATE_LIMIT_WINDOW_MS || '900000', 10),
        MAX_REQUESTS: parseInt(process.env.RATE_LIMIT_MAX_REQUESTS || '100', 10)
      },
      
      CORS: {
        ALLOWED_ORIGINS: (process.env.ALLOWED_ORIGINS || '*').split(',')
      }
    };
    ```
  </action>
  <acceptance_criteria>
    - .env.example exists with PORT, MONGODB_URI, JWT_SECRET, JWT_EXPIRES_IN
    - api/src/config/index.ts exports config object with PORT, DATABASE, JWT, RATE_LIMIT, CORS
    - Config uses process.env with defaults
    - No hardcoded secrets (JWT_SECRET has default "dev-secret..." for dev only)
  </acceptance_criteria>
  <verify>
    <automated>cat api/.env.example | head -10 && echo "---" && cat api/src/config/index.ts | head -20</automated>
  </verify>
  <done>Environment configuration with .env.example template and config loader</done>
