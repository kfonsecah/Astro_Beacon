<task type="auto">
  <name>Task 1: Define entities, attributes, and relationships from project requirements</name>
  <files>.planning/docs/DATA-DESIGN.md</files>
  <action>
    Create `.planning/docs/DATA-DESIGN.md` with a complete data design document. Derive entities from the professor's requirements and the 13 reference screens. Each entity must have: name, attributes (with types), primary key, and relationships.

    Required entities (from requirements + reference screens):

    1. **Astronauta (Astronaut)** — Core user entity
       - id: string (UUID)
       - name: string
       - role: string (e.g., "astronaut")
       - status: enum (active, inactive, emergency)
       - currentPlanet: string
       - baseCampLocation: { lat: number, lng: number }
       - createdAt: Date
       - lastActiveAt: Date

    2. **Recurso (Resource)** — Inventory items (oxygen, food, water, etc.)
       - id: string (UUID)
       - name: string
       - category: enum (oxygen, food, water, medical, equipment, other)
       - currentAmount: number
       - maxCapacity: number
       - unit: string (e.g., "L", "kg", "units")
       - minAlertThreshold: number (triggers alert when below this)
       - alwaysVisible: boolean (must be visible on HUD)
       - updatedAt: Date

    3. **RecursoMovimiento (ResourceMovement)** — Income/expense registry
       - id: string (UUID)
       - resourceId: string → Resource (FK)
       - type: enum (income, expense)
       - amount: number
       - reason: string
       - recordedAt: Date
       - relatedTripId: string → Trip (FK, nullable)

    4. **Especie (Species)** — Catalog of discovered life forms
       - id: string (UUID)
       - name: string (may be "Unknown" until classified)
       - classification: enum (animal, plant, resource, microorganism, unknown, other)
       - dangerLevel: enum (friendly, cautious, dangerous, lethal)
       - description: string
       - imageUrl: string
       - discoveredAt: Date
       - classifiedByAI: boolean
       - aiConfidence: number (0-1)

    5. **BitacoraEntrada (LogbookEntry)** — Discovery journal entries
       - id: string (UUID)
       - astronautId: string → Astronaut (FK)
       - speciesId: string → Species (FK, nullable)
       - description: string
       - imageUrl: string
       - location: { lat: number, lng: number }
       - createdAt: Date
       - isOffline: boolean (was created offline)
       - syncedAt: Date (nullable)

    6. **Viaje (Trip)** — Exploration trips to collect resources
       - id: string (UUID)
       - astronautId: string → Astronaut (FK)
       - destination: { lat: number, lng: number }
       - status: enum (planned, active, completed, aborted)
       - startedAt: Date (nullable)
       - completedAt: Date (nullable)
       - oxygenBudget: number (planned oxygen for trip)
       - oxygenConsumed: number
       - resourcesCollected: number (count of resources gathered)
       - notes: string

    7. **Suministro (SupplyDrop)** — NASA supply drops with GPS
       - id: string (UUID)
       - location: { lat: number, lng: number }
       - status: enum (pending, delivered, collected, expired)
       - contents: ResourceItem[] (array of {resourceId, amount})
       - droppedAt: Date
       - expiresAt: Date
       - collectedAt: Date (nullable)

    8. **Sesion (Session)** — Authentication and session management
       - id: string (UUID)
       - astronautId: string → Astronaut (FK)
       - token: string
       - expiresAt: Date
       - lastActivityAt: Date
       - isActive: boolean

    Document relationships:
    - Astronaut 1:N ResourceMovements
    - Astronaut 1:N LogbookEntries
    - Astronaut 1:N Trips
    - Astronaut 1:N Sessions
    - Resource 1:N ResourceMovements
    - Species 1:N LogbookEntries
    - Trip 1:N ResourceMovements
    - SupplyDrop N:M Resources (via contents array)

    Include a Mermaid ER diagram showing all entities and relationships.
  </action>
