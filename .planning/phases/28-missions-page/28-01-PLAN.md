<objective>
**Phase 28 — Missions Page: New tab screen showing mission/expedition history + active mission monitoring + ability to plan expeditions**

**Purpose:** Dedicated missions tab that separates the concept of "mission log" from the active trip GPS flow in `/trips`. Users can see active mission status in real time, browse past missions (completed/aborted) with pagination, complete or abort the current mission, and initiate new expeditions.

**Output:**
- `app/(tabs)/missions.tsx` — Main tab screen (active panel + history list + CTAs)
- `app/missions/[id].tsx` — Read-only detail screen for past missions
- Updated `app/(tabs)/_layout.tsx` — Added missions tab entry (flag icon)
- Updated `app/(tabs)/dashboard.tsx` — EXPEDICIÓN button now points to `/missions`

**Design System:** Follow UI-SPEC color/typography/spacing tokens. All copy in Spanish, uppercase HUD convention. Zero hardcoded hex values — use `tc.*` from theme and `colors.*` from constants.
</objective>
