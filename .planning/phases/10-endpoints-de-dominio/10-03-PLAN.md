Create TripService with full lifecycle management:

**CRUD (TRIP-01, TRIP-04):**
- create(userId, input): Create trip with status 'planificado'
- findAll(userId, page, limit, status?): Filter by optional status
- findOne(userId, tripId): Single trip or throw 404
- update(userId, tripId, input): Update fields (only if status is 'planificado' or 'activo')
- delete(userId, tripId): Remove trip

**Trip Lifecycle (TRIP-02, TRIP-03):**
- startTrip(userId, tripId):
  - Validate status is 'planificado'
  - Set status to 'activo'
  - Set startDate to now
- endTrip(userId, tripId, status: 'completado' | 'abortado'):
  - Validate status is 'activo'
  - Set status to input ('completado' or 'abortado')
  - Set endDate to now
  - Calculate O2Consumed based on duration and config

**O2 Tracking (TRIP-05, D-14):**
- calculateO2Consumed(trip):
  - If startDate and endDate: hours = (endDate - startDate) / 3600000
  - baseConsumption = hours * O2Config.baseRate
  - manualAdjustments = sum of manualAdjustments array
  - return baseConsumption + manualAdjustments
- addManualAdjustment(userId, tripId, amount, note):
  - Validate trip is 'activo'
  - Push to O2Config.manualAdjustments array
  - Recalculate O2Consumed
- updateO2Config(userId, tripId, baseRate):
  - Validate trip is 'activo'
  - Update O2Config.baseRate
  - Recalculate O2Consumed

Use Date math for duration calculations.
