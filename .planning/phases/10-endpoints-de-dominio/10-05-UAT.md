# Phase 10 UAT Test Script

## Setup

1. Start server: `cd api && npm run dev`
2. Register new account (or use existing)
3. Login to obtain `accessToken`

## Authentication Tests

| Test                            | Endpoint                | Method | Expected | Actual |
| ------------------------------- | ----------------------- | ------ | -------- | ------ |
| Register new user               | `/api/v1/auth/register` | POST   | 201      | 201    |
| Register duplicate email        | `/api/v1/auth/register` | POST   | 409      | 409    |
| Login fails with wrong password | `/api/v1/auth/login`    | POST   | 401      | 401    |
| Missing token returns 401       | `/api/v1/auth/login`    | GET    | 401      |        |
