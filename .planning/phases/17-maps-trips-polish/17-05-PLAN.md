# Plan 17-05: Fix Map Panning + Request Supply Feature

## Objective
Fix map panning issue by extracting MapView to fixed header, and add "Request Supply" feature that creates randomized supply packages near user's location.

## Tasks

### Task 1: Restructure map.tsx layout
**Files:** `app/(tabs)/map.tsx`

Move MapView from `FlatList ListHeaderComponent` to a fixed `View` above the FlatList.
- Create a container with MapView (height: 200px or 30% screen) + FlatList below
- Map gestures (pan, zoom) now work independently from list scroll
- Test: sliding finger on map should pan/zoom

### Task 2: Add "Request Supply" floating button
**Files:** `app/(tabs)/map.tsx`, `src/hooks/useSupplies.ts`

Add circular floating button (bottom-right of map section).
On press:
1. Get current GPS location via `Location.getCurrentPositionAsync()`
2. Generate random location near user: `{lat: userLat + random(-0.01, 0.01), lng: userLng + random(-0.01, 0.01)}`
3. Randomize supply data:
   - `name`: `"Suministro #${Date.now().toString(36)}"`
   - `description`: Random from ["Emergency cache", "Supply drop", "Resource cache", "Emergency box", "Supply package"]
   - `contents`: 1-3 random items from `["oxigeno", "agua", "comida", "medicinas", "herramientas"]`
   - `status`: `"pendiente"`
   - `expiresAt`: `new Date(Date.now() + random(24-72) * 3600000)`
   - `userId`: from auth store
4. Call `useCreateSupply()` mutation
5. On success: invalidate queries to refresh list

### Task 3: Update supply service/hook
**Files:** `src/services/supply.service.ts`, `src/hooks/useSupplies.ts`

- Ensure `supplyService.create()` accepts full `CreateSupplyInput`
- Add `useCreateSupply()` mutation in `useSupplies.ts`
- Mutation invalidates `'supplies'` query key to refresh list
- Include all fields: name, description, location, contents, status, expiresAt

## Verification

- [ ] Map pans/zoom with finger gesture (not scrolling list)
- [ ] Floating button visible on map (bottom-right)
- [ ] Pressing button creates supply near user location
- [ ] New supply appears in list after creation
- [ ] Supply has randomized contents (1-3 items)
- [ ] Supply has `status: "pendiente"` and future `expiresAt`
